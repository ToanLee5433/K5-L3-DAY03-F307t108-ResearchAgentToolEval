💡 Câu hỏi mẫu để thử nghiệm

  • Tin tức AI nổi bật nhất hôm nay
    → Agent gọi lookup(query="AI") và format thành markdown digest.
  • Xem các bài đăng gần nhất của tài khoản sama trên X
    → Agent tự map tên tài khoản và gọi timeline(screenname="sama").
  • Đổi 100 USD sang tiền Việt Nam (VND)
    → Agent gọi tool mới currency_exchange tính ra 2.545.000 VND.
  • Đăng bản tin công nghệ mới lên Telegram giúp tôi
    → Kích hoạt guardrail an toàn: clarify(response_type="yes_no") xin phép.

🛠️ Danh mục công cụ (Tool Registry)

Tên Tool Chức năng & Nhiệm vụ Loại Tool Ranh giới / Guardrail
clarify Hỏi lại người dùng khi thiếu tham số bắt buộc hoặc yêu cầu xác nhận hành động có rủi ro. Control Chặn suy đoán mò mẫm, yêu cầu yes_no trước hành động side-effect.
lookup Tra cứu tin tức và thông tin web thời sự theo từ khóa và timeframe (Tavily API). Live API Trích xuất query súc tích, lọc thời gian theo timeframe thay vì query expansion.
social_search Tìm kiếm các bài thảo luận, quan điểm dư luận mới nhất trên X/Twitter (RapidAPI). Live API Dùng cho chủ đề chung, phân biệt với tài khoản cá nhân cụ thể.
timeline Đọc dòng thời gian tweet của một tài khoản Twitter/X cụ thể theo handle (RapidAPI). Live API Bỏ ký tự '@' ở đầu handle, giới hạn số lượng bài đăng (limit).
fetch Cào và trích xuất nội dung văn bản đầy đủ từ một đường dẫn URL (Firecrawl API). Live API Bắt buộc có URL hợp lệ, cắt ngắn văn bản markdown chống tràn context.
currency_exchange Tra cứu tỷ giá và tính toán quy đổi ngoại tệ (USD, EUR, VND, JPY, GBP, AUD,...). Tool mới Kiểm tra mã tiền ISO 4217, bắt lỗi số tiền âm/lỗi kiểu dữ liệu, fallback offline.
format Định dạng các thông tin thô thu thập được thành bản tin markdown chuyên nghiệp. Local Formatter Giữ tối đa 5 items tiêu biểu kèm trích dẫn URL nguồn.
send Gửi bản tin tổng hợp lên kênh Telegram công cộng của nhóm. Action Bắt buộc có cờ confirmed=True từ người dùng mới được gửi.
